# CAD-Austauschdateien

Hier liegen später neutrale CAD-Exporte, beispielsweise STEP, soweit das gewählte Werkzeug sie unterstützt. Noch keine Exporte vorhanden.

Zu jedem Export Bauteilkennung, Revision, Quelldatei, Quell-Commit, Exportformat und Einheit dokumentieren. Exporte aus den nativen Quellen erzeugen; Geometrieänderungen dort durchführen.
