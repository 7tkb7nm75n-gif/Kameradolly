# Stückliste

Die Datei [parts.csv](parts.csv) ist als leere Stücklistenvorlage vorbereitet. Es sind noch keine Kaufteile, Mengen oder Druckmaterialien ausgewählt.

Je Position Kennung, Baugruppe, Typ (`Druckteil` oder `Kaufteil`), Bezeichnung, Menge, Spezifikation und Revision ergänzen. Bei Druckteilen die Quelle, bei Kaufteilen eine eindeutige Hersteller-/Artikelreferenz oder vollständige Spezifikation eintragen. Unbekannte Werte als `offen` kennzeichnen.
