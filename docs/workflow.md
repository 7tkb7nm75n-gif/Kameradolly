# Gemeinsam Schritt für Schritt

## 1. Projekt verstehen – jetzt erledigt

Im Repository auf der Startseite die README lesen, dann die technische Spezifikation öffnen. Die Ordner sind vorbereitet. CAD- und Druckdateien entstehen in den folgenden Schritten.

## 2. Eingangsdaten aufnehmen – nächster Arbeitsschritt

Dieses Blatt im nächsten Gespräch oder hier im Repository ausfüllen. Unbekannte Werte bleiben ausdrücklich offen.

| Eingabe | Wert |
| --- | --- |
| Kamera und Objektiv | offen |
| Kopf, Platte und weiteres mitfahrendes Zubehör | offen |
| Gesamtmasse aller mitfahrenden Teile | offen |
| Gewünschter nutzbarer Fahrweg | offen |
| Einsatzlage und mögliche Abstützung | offen |
| Drucker / Verfahren und Bauraum X/Y/Z | offen |
| Vorhandenes Material und nutzbare Kaufteile | offen |
| Manuelle Fahrt oder Motorisierung / Aufnahmezweck | offen |
| Vorhandener Kameraanschluss / Kopf mit Anschlussmaßen | offen |
| Verfügbares CAD-Werkzeug | offen |

Für das erste Layout zuerst Kamerasystem samt Masse, Fahrweg/Einsatzlage und Fertigungsmöglichkeiten klären. Die übrigen Punkte spätestens vor dem jeweiligen Detailentwurf entscheiden; siehe [Entscheidungen](decisions.md).

## 3. Layout von Schiene und Wagen

Aus den Eingangsdaten ein gemeinsames Layout mit Lastschwerpunkt, Auflagen, Fahrweg und Wagenbauraum erstellen. Führung auswählen, dann Schnittstellen S-01 und S-02 eintragen. Ergebnis: ein editierbarer Layoutstand mit dokumentierten Maßen.

## 4. Baugruppen detaillieren

Schiene und Wagen konstruktiv abstimmen. Danach Antrieb gemäß gewählter Betriebsart und Kameraaufnahme anhand des realen Anschlusses ausarbeiten. Schnittstellen S-03 bis S-05 dokumentieren und die Stückliste füllen. Vor einer Druckfreigabe Montagezugang und Freigängigkeit prüfen.

## 5. Kleine Passprobe drucken

Zuerst nur kritische Anschluss- und Führungsausschnitte drucken. Druckorientierung, Material, Profil und gemessene Passungen dokumentieren. Korrekturen in den CAD-Quellen vornehmen, danach Exporte neu erzeugen.

## 6. Prototyp montieren und prüfen

Prüfkriterien vorab numerisch festlegen. Den Prototyp gemäß [Prüfplan](../validation/README.md) zunächst unbelastet und dann mit Ersatzlast prüfen. Jede Änderung erhält einen nachvollziehbaren CAD-/Exportstand.

## 7. Ersten geprüften Stand kennzeichnen

Erst nach dokumentiertem Ergebnis einen Versionsstand als für den geprüften Lastfall geeignet kennzeichnen. Dazu gehören CAD-Quellen, Druckdateien, Druckparameter, Stückliste, Montagefolge und Prüfbericht. Eine Prüfung gilt nur für die dokumentierte Konfiguration.
