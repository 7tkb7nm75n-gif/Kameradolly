# CAD-Quellen

Hier liegen später die editierbaren nativen Modelle. Das CAD-System ist noch offen.

| Unterordner | Baugruppe |
| --- | --- |
| [rail/](rail/README.md) | Schiene, Verbindungen, Abstützung und Anschläge |
| [carriage/](carriage/README.md) | Wagen und Führungselemente |
| [drive/](drive/README.md) | Antrieb, feste Halter und Wagenanbindung |
| [camera_mount/](camera_mount/README.md) | Kameraaufnahme und Adapter |

Das Gesamtmodell kann nach Werkzeugwahl hier ergänzt werden. Gemeinsame Parameter und Bezugsebenen mit dem ersten Layout dokumentieren. Austauschmodelle gehören nach `exports/`, Druckdateien nach `printing/`.

Bauteilkennung, Revision und Einheiten im Modell dokumentieren. Ein Export verweist auf die zugehörige native Quelle und deren Git-Stand.
