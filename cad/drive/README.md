# Antrieb

Platz für native Modelle der gewählten Antriebslösung und ihrer Halter. Noch keine Geometrie vorhanden; manuell oder motorisiert bleibt offen.

Vor einer Teileauswahl Betriebsart und benötigte Kräfte bestimmen. Schnittstellen S-03 und S-04 gemäß [Spezifikation](../../docs/technical-specification.md) dokumentieren. Steuerung und Elektronik nur ergänzen, falls Motorisierung entschieden wird.
