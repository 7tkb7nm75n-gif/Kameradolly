# Schiene

Platz für native Modelle der Schiene, Abstützung, Verbindungen und Endanschläge. Noch keine Geometrie vorhanden.

Vor dem Detailentwurf: Fahrweg, Lastfall, Führung und Auflagepunkte festlegen. Schnittstellen S-01, S-02 und S-03 gemäß [Spezifikation](../../docs/technical-specification.md) dokumentieren.
