# Kameraaufnahme

Platz für native Modelle der Kameraaufnahme und ihrer Adapter. Noch keine Geometrie vorhanden.

Das reale kameraseitige Gegenstück einschließlich Anschluss und Einschraubtiefe aufnehmen. Schnittstelle S-05 gemäß [Spezifikation](../../docs/technical-specification.md) dokumentieren; kein Gewinde voraussetzen.
